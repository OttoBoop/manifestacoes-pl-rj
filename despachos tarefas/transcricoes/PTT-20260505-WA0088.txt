Olha, existem algumas maneiras de sistematizar essas pesquisas, inclusive de encontrar papers e dados especificamente a partir de ter visto o projeto de lei específico com LLMs, mas é importante saber o custo de não ter um humano fazendo essas coisas. E o principal custo é que nós humanos vamos perder compreensão, porque se a gente ler cada um dos papers para encontrar o dado mais relevante, então a gente vai entender muito melhor o que está o valor desse projeto de lei de fato. Se a gente coloca para uma máquina sistematicamente olhar aquilo, o mais interessante é ter um resumo desses papers, um direcionamento para saber os benefícios, um direcionamento para pesquisa mona.
